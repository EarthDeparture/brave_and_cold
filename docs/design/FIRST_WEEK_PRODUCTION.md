Baseline ccf1c79. Checkpoint checkpoint/pre-first-week-production-2026-10-05. Branch codex/first-week-production. No remote push. Preserve all existing terrain, roads, tower geometry and unrelated work. Each batch gets its own local commit and tests before subsequent work.

Original Blender metre-scale timber/cache/water equipment, native source and hashes; under 20k triangles per location, at most eight small material surfaces per prop, no blocking decoration on walking lane.

3. Survival and handling: separate fatigue from short-term stamina with saved state, gradual movement/stamina effects and warm resting. Repair worn tools and damaged clothing with finite material costs. Clarify drying and treatment. Reusable first-person treatment, switch, stove and wristwatch presentation while preserving grip contacts. Review outbreak infection separately from ordinary wound infection; retain existing save meaning.
4. Narrative and finish: original personal city connection and recurring dispatch/coworker story; useful optional physical clues. Refine location materials, light readability and weather response using the existing art direction. Original local foley, radio text/performance continuity. Existing locally synthesized speech remains identified as development performance unless a directed human performance is available. Profile populated route and save restoration; no unsupported AAA/performance claims.

Acceptance per batch: real interaction paths; cancellation, resource conservation, bounded visuals, save/load and legacy migration; actual GPU views from player height in daylight/night/storm; walking clearance; baseline regressions. Complete first-week diagnostic including ignored optional work and missed radio. Use in-memory test snapshots, never user save files. Separate renderer assertions from static mesh checks. Compare same cameras/conditions before and after when revising existing materials. Preserve all source/licence/provenance and review images. Reject intersecting, floating, unreadable or visibly repetitive candidates and iterate.

Production stays local: game-dev CLI is unavailable on this host; use the already established local Blender 5.2/Python pipeline. No provider jobs, paid assets, credential access or new software installation. Original asset outputs: tools/blender/generated/first_week and brave-and-cold/assets/first_week. QA outputs: brave-and-cold/shots/first-week. New modular gameplay belongs in systems/prepared_water.gd and world/first_week_route.gd before expansion; world integration should remain narrow. Complete all batches sequentially; this document is a plan, not a receipt of features delivered.
