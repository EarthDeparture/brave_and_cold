# Brave and Cold

*Survive the cold. Survive the dead.*

![A remote fire lookout above a snow-covered Canadian forest at dusk.](brave-and-cold/assets/ui/menu_bg_lookout.jpg)

**Brave and Cold** is an upcoming first-person survival horror game set in northern Canada. An isolated work posting becomes a fight to stay alive as an outbreak spreads through the surrounding region.

Explore a snowbound valley, maintain shelter and manage food, warmth and supplies. Each trip outside calls for preparation, with changing weather, wildlife and the infected shaping the journey. A painterly winter landscape provides the setting for quiet exploration and an unfolding crisis.
